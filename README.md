# 磁场发射器 结构方案查看器 V0.3（一体化三用途）

## 怎么看

双击 `index.html`，用浏览器（Chrome/Edge）打开即可，无需安装任何软件。

## 操作

- 左键拖拽：旋转视角
- 滚轮：缩放
- 右键拖拽：平移
- 右上方面板：切换 单只 / 多只 / 体外 三种模式、自动旋转、线框、网格

## 三种用途（一台整机）

| 模式 | 名称 | 用途 |
| --- | --- | --- |
| 单只 | 单只模式（1 通道） | 麻醉小鼠单只刺激，中间通道工作 |
| 多只 | 多只模式（5 通道并行） | 5 只小鼠并行刺激，半开放隧道腔体 |
| 体外 | 体外模式（Helmholtz 线圈模块） | 专用可拆换模块（环内径约 180 mm，自带底座，主机共用），培养板置于两环中央均匀区 |

## 文件说明

- `index.html`：3D 查看器（离线可用）
- `data.js`：内嵌几何数据（自动生成）
- `sim.html` + `sim_data.js`：体外模块 Helmholtz 仿真结果（磁场热图/轴线曲线/热参数）
- `stl/`：STL 网格文件（3D 打印/网格验证用）
- `lib/`：Three.js 渲染库

## 重新生成

参数或结构变更后，运行：

```powershell
python work/build_structure_models.py
python work/build_viewer_data.py
```

刷新页面即可看到更新后的模型。

> 当前模型为参数初稿（依据《结构规格书_一体化三用途_V0.3》），用于结构评审；STEP 工程文件待确定 CAD 平台后输出。
